# AI Impact on Students: Academic Performance and Well-being Analysis

## Overview

This project investigates how the use of Generative AI tools influences student academic performance, study habits, and psychological well-being.

Using a dataset of 50,000 students, I conducted an exploratory and statistical analysis to evaluate whether AI adoption is associated with changes in GPA, perceived dependency on AI, anxiety levels, and skill retention.

## Dataset

Source: Kaggle

The dataset contains information about:

* student major and year of study;
* weekly Generative AI usage;
* traditional study hours;
* GPA before and after the semester;
* perceived AI dependency;
* exam anxiety level;
* skill retention score;
* burnout and well-being indicators.

## Project Goals

* Explore patterns of Generative AI adoption among students.
* Measure changes in academic performance during the semester.
* Determine whether GPA changes are statistically significant.
* Investigate relationships between AI usage, anxiety, dependency, and learning outcomes.
* Identify groups that benefit most from AI-assisted learning.
